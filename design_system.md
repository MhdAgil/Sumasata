# 2.1 — DESIGN DIRECTION

## 1. Konsep Desain

Sumasata mengusung konsep **Minimalist Editorial Design** yang menggabungkan estetika majalah perjalanan dengan kemudahan penggunaan platform eksplorasi destinasi modern.

Desain diarahkan untuk memberikan pengalaman visual yang elegan, premium, tenang, dan adventurous.

## 2. Karakter Visual

- Minimalist dan modern.
- Editorial / magazine-inspired layout.
- Generous whitespace.
- Immersive photography.
- Storytelling-driven content.
- Asymmetrical composition secara selektif.
- Subtle cultural identity.
- Subtle micro-interactions dan animations.

## 3. Prinsip Desain

**Photography First**  
Menggunakan fotografi berkualitas tinggi sebagai elemen visual utama.

**Visual Hierarchy**  
Menyusun informasi berdasarkan tingkat kepentingannya.

**Content Readability**  
Mengutamakan kenyamanan membaca dan navigasi.

**Cultural Identity**  
Menghadirkan identitas budaya Sumatra melalui elemen visual yang subtil, seperti:
- Traditional geometric motifs.
- Topographic contour lines.
- Minimalist map illustrations.
- Architectural inspirations.

**Responsive Design**  
Desain harus menyesuaikan berbagai ukuran layar tanpa mengorbankan hierarki visual dan keterbacaan.

## 4. Design Statement

Sumasata merupakan platform eksplorasi destinasi dan budaya yang menggabungkan desain editorial minimalis, fotografi imersif, storytelling yang bermakna, serta identitas budaya yang subtil untuk merayakan keindahan Sumatra.

Pengalaman dan rekomendasi eksplorasi yang dikurasi.

- Terstruktur.

# 2.3 — COLOR PALETTE

Sumasata menggunakan kombinasi warna Navy, Cream, dan Antique Gold.

## 1. Official Color Palette

| Color | HEX Code | Role |
|---|---|---|
| Deep Muted Navy | `#293B50` | Primary |
| Warm Cream | `#F2EBDD` | Background |
| Antique Gold | `#B49A68` | Accent |
| Off-white | `#FFFEFA` | Secondary Background |
| Soft Gray | `#D9D9D4` | Neutral |

## 2. Color Usage

**Deep Muted Navy — `#293B50`**
- Navigation.
- Headlines.
- Footer.
- Brand elements.

**Warm Cream — `#F2EBDD`**
- Dominant page background.
- Main visual identity.

**Antique Gold — `#B49A68`**
- Accent buttons.
- Decorative lines.
- Icons.
- Highlights.

**Off-white — `#FFFEFA`**
- Alternate section backgrounds.
- Cards and content surfaces.

**Soft Gray — `#D9D9D4`**
- Borders.
- Dividers.
- Secondary UI elements.

### Color Principle

Antique Gold digunakan secara terbatas agar tidak mendominasi tampilan.

Warm Cream menjadi warna latar utama, sementara Deep Muted Navy memberikan kontras dan karakter visual.

Catatan: Pengujian kontras dan aksesibilitas akan dilakukan pada tahap validasi desain.

# 2.4 — TYPOGRAPHY & SPACING

## 1. Font Pairing

Sumasata menggunakan kombinasi dua jenis font:

**Primary Typeface — Playfair Display**
Digunakan untuk:
- Display headline.
- Page headings.
- Section headings.
- Destination titles.

Karakter: Elegant, editorial, expressive.

**Secondary Typeface — DM Sans**
Digunakan untuk:
- Navigation.
- Body text.
- Buttons.
- Metadata.
- Captions.

Karakter: Modern, clean, readable.

## 2. Typography Scale

Sistem ukuran menggunakan pendekatan **Modular Type Scale**.

Konfigurasi:
- Base font size: 16 px.
- Scale ratio: 1.25.
- Scale name: Major Third.
- Scale direction: Balanced.

### Official Typography Hierarchy

| Hierarchy | Font | Size |
|---|---|---:|
| Display | Playfair Display | 49 px |
| H1 | Playfair Display | 39 px |
| H2 | Playfair Display | 31 px |
| H3 | Playfair Display | 25 px |
| Body | DM Sans | 16 px |
| Small | DM Sans | 13 px |
| Caption | DM Sans | 10 px |

## 3. Typography Usage

**Display**
Digunakan untuk headline utama pada Hero Section.

**H1**
Digunakan untuk judul utama halaman.

**H2**
Digunakan untuk judul setiap section.

**H3**
Digunakan untuk judul kartu destinasi dan subbagian.

**Body**
Digunakan untuk paragraf dan deskripsi.

**Small**
Digunakan untuk informasi pendukung.

**Caption**
Digunakan untuk kategori, label, dan metadata.

## 4. Responsive Typography

Ukuran di atas merupakan acuan awal untuk desktop.

Ukuran mobile akan disesuaikan melalui proses wireframing dan evaluasi responsif.

Tidak semua ukuran harus diperkecil dengan rasio yang sama. Setiap hierarki perlu diuji berdasarkan keterbacaan dan komposisi layout.

## 5. Spacing

Sistem spacing belum dikunci secara final.

Penentuan spacing akan dilakukan pada tahap wireframing dengan mempertimbangkan:
- Content hierarchy.
- Whitespace.
- Section separation.
- Component spacing.
- Mobile readability.
